# Домашняя ферма кур-несушек

Проект небольшой домашней птицефермы яичного направления (50 голов, формат ЛПХ). Репозиторий содержит бизнес-документацию проекта: продуктовые требования, бизнес-план и сайт-презентацию.

## Содержимое репозитория

| Файл | Описание |
|---|---|
| `prd.md` | PRD — цели, объём проекта, требования, финансы, риски, дорожная карта |
| `business_plan.docx` | Бизнес-план в формате Word |
| `prd.pdf` | PDF-версия PRD |
| `index.html` | Одностраничный сайт-презентация проекта |

## Ключевые цифры

- Поголовье на старте: **50 голов**
- Стартовые вложения: **≈ 400 000 – 630 000 ₸**
- Ежемесячная прибыль: **20 000 – 35 000 ₸**
- Окупаемость: **15–20 месяцев**

## Просмотр сайта

Откройте `index.html` в браузере — сайт не требует сборки или зависимостей.

## Статус

Черновик, версия 1.0 (2026).
